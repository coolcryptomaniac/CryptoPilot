# CPT chain strategy toward 2030

This is an ecosystem-fit forecast, not a CPT or chain price forecast.

## Recommended order

1. **Ethereum ecosystem / Base as canonical app deployment** — strongest institutional liquidity, stablecoin/RWA depth, EVM security tooling and direct fit with Coinbase/USDC infrastructure. Keep a single canonical CPT supply; Base is preferred for low-cost app utility while Ethereum mainnet remains the security/liquidity anchor.
2. **Solana as the second deployment** — add only when CryptoPilot has real high-frequency consumer/social/reward activity. Use Token-2022/SPL tooling and a controlled canonical bridge/mint-burn design after audit.
3. **BNB Chain as the third deployment** — useful for broad retail/CEX distribution and EVM compatibility. Deploy only after user demand justifies splitting liquidity.
4. **TRON as a grant/use-case pilot** — compelling for stablecoin payments, agentic payments and TRON Builders League alignment. Treat it as an ecosystem-specific product integration rather than the canonical CPT home today.

## Rules

- Do not independently mint 100M CPT on multiple chains.
- Canonical supply must remain globally bounded.
- Cross-chain mint/burn/lock controls require an independent security audit.
- No public token sale, guaranteed yield, revenue-share promise or price-appreciation promise is enabled by this repository.
- Token utility should be tied to real product usage: subscription discounts, contribution/reputation rewards and bounded governance.

## Revisit quarterly

Review developer activity, stablecoin liquidity, institutional adoption, grant availability, bridge security, regulatory environment, active CryptoPilot users by chain and actual transaction demand before adding a new chain.
