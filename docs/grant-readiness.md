# CryptoPilot grant readiness

CryptoPilot does not claim automatic grant eligibility. The app maintains a **Grant Passport** that maps shipped evidence to public program criteria and highlights missing work.

## Evidence already in the repository

- Open-source public repository and reproducible CI.
- Paper-first trading and deterministic risk controls.
- Wallet authentication and encrypted per-user exchange credentials.
- User-signed DEX execution architecture.
- USDC subscription/payment plumbing.
- Backtesting and audit trails.
- Telegram status integration.
- Public documentation and milestone-oriented engineering.

## High-value gaps before applications

- Public deployed demo and uptime/status evidence.
- Real usage/traction metrics and cohort retention.
- Independent security review / smart-contract audit.
- Founder/team profile and legal-entity information.
- Chain-specific testnet/mainnet integrations for Solana, TRON, BNB, Arbitrum, Avalanche, NEAR, Superchain and TON rather than generic claims.
- Program-specific milestone budget, measurable ecosystem impact and application narrative.
- Public-good/open-source module tailored for Ethereum/Solana-style public-good programs.

## Tracked programs

The Worker `/api/grants` registry includes major programs such as TRON Builders League, Solana Foundation Funding, Circle Developer Grants, BNB Chain MVB, Ethereum Foundation ESP, Arbitrum Open House, Avalanche Build Games, NEAR Funding, Optimism/Superchain support and TON Ecosystem Support.

Each entry has an official program URL, current status snapshot, funding description, public focus areas and a readiness score based on concrete repository evidence.

Program terms change. Always re-check the official program before submitting.
